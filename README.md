#  NETWORKING: Ruta de Redes para Administración IT

¡Bienvenido a mi repositorio de redes! Este espacio está diseñado para documentar mi aprendizaje práctico, paso a paso, 
Sobre los conceptos fundamentales de networking aplicados al mundo real de la Administración de Sistemas y Soporte IT.

##  ¿Por qué estoy haciendo esto?
Como futuro administrador IT, entendí que un buen sistema (como Windows Server, Active Directory o la nube) no sirve de nada si la red que lo sostiene falla. 
Este repositorio nace para construir una **base técnica sólida**, pasando de la teoría a la práctica utilizando herramientas estándar de la industria como **Cisco Packet Tracer**, 
Comandos de Windows y escenarios reales de solución de problemas.

##  ¿Qué vamos a ver aquí?
A lo largo de este repositorio, abordaré y documentaré los siguientes pilares de redes, 
enfocándome en comprender el *porqué* de las cosas y no solo en memorizar comandos:

* **Infraestructura Base:** Direccionamiento IP, configuración de redes locales (LAN/WAN) y conectividad inalámbrica (Wi-Fi).
* **Servicios Esenciales:** Cómo operan y se configuran los servidores de nombres (**DNS**) y de asignación automática de direcciones (**DHCP**).
* **Seguridad y Acceso:** Implementación y comprensión de túneles seguros (**VPN**).
* **Kit de Supervivencia y Troubleshooting:** Uso práctico de comandos de diagnóstico diario (`ping`, `ipconfig`, `nslookup`, `tracert`).

##  ¿Para qué servirá esta práctica?
Cada carpeta o documento en este repositorio representará:
1. **Laboratorios funcionales:** Montados y probados virtualmente en Cisco Packet Tracer.
2. **Guías de referencia rápida (*Cheatsheets*):** Creadas con mis propias palabras para resolver problemas reales cuando un usuario o equipo falle en la red.
3. **Evidencia para mi carrera:** Un registro tangible de mi evolución técnica y de mi capacidad para documentar procesos, listo para ser mostrado a futuros reclutadores.
